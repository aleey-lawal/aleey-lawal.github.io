## Overview
Built a regression pipeline to predict laptop prices from hardware
specifications. Includes data cleaning, feature engineering on categorical
specs (brand, CPU series, GPU type), model training and evaluation, and
feature importance analysis to identify the strongest price drivers.

## Tech Stack
Python · scikit-learn · Pandas · NumPy · Matplotlib · Seaborn
