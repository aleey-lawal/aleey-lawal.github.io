## Overview
Built an end-to-end machine learning pipeline that simultaneously predicts
shoe sizes in five international standards (EU, US, UK, JP, CN) from a
person's physical and foot measurements, with regional variation grounded
in the Volumental 1.2M foot scan study.

## Key Results
- **Average R² ≈ 0.9958** across all 5 size standards
- **Average MAE ≈ 0.088** size units — accurate to within half a shoe size
- Covers **22 countries** across **5 global regions**
- Interactive 3-tab Streamlit app with size explorer and global insights

## Data Sources
- Jurca et al. (2019) — Analysis of 1.2M foot scans, *Scientific Reports*
- Wunderlich & Cavanagh (2001) — Gender differences in adult foot shape
- WHO Global Health Observatory — Regional anthropometric averages

## Tech Stack
Python · scikit-learn · Streamlit · Pandas · NumPy · Plotly · Joblib
